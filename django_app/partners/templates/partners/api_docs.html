🏛️ دليل تكامل واجهات الشركاء وخدمات SaaS (Headless API)

يتيح لك هذا الـ API بناء وتضمين خدمة المساعد الصوتي الذكي داخل تطبيقك أو متجرك أو نظامك السحابي دون أن يرى عميلك واجهتنا مطلقاً (White-Label / Headless Architecture). تتم محاسبتك بسعر الجملة المخفض المخصص لك بخصم مباشر من محفظتك المركزية مع التقريب الصارم لأعلى دقيقة.

طريقة المصادقة (Authentication Header): Required Header

يجب تمرير مفتاح الشريك في هيدر كل طلب:

X-Partner-Key: sk_live_prt_your_secret_key_here

عنوان الخادم الأساسي (Base URL): {{ base_url }}/api/partner/v1/

🏢تسجيل وإدارة العملاء (Clients Management)

POST /api/partner/v1/clients/register/
تسجيل عميل جديد

يسجل متجراً أو عميلاً فرعياً تابعاً لشركتك خلفياً ويعيد client_id لتقوم بتخزينه في قاعدة بياناتك.

Request Body (JSON)
{
  "external_reference": "sub_store_9942",
  "name": "متجر النور التجريبي",
  "email": "store9942@saas-demo.com",
  "spending_cap": 25.00,
  "minute_cap": 200
}
Response (201 Created)
{
  "status": "success",
  "client_id": 19,
  "name": "متجر النور التجريبي",
  "external_reference": "sub_store_9942",
  "spending_cap": 25.0,
  "minute_cap": 200
}
GET /api/partner/v1/clients/
عرض جميع العملاء

استعراض قائمة كافة عملاء الساس وإحصائيات استهلاك كل عميل وسقوف الاستخدام.

👨‍💼دليل الموظفين والتحويلات (Employees Full CRUD)

GET POST /api/partner/v1/clients/{client_id}/employees/
دليل الموظفين

إضافة موظفين جدد وتحويلات داخلية خاصة بهذا العميل فقط مع عزل تام (Multi-Tenant Isolation).

POST Body (إنشاء موظف جديد)
{
  "display_name": "سارة الخالد",
  "extension": "102",
  "department": "خدمة العملاء والدعم الفني",
  "password": "SecurePassword123",
  "status": "ready"
}
Response (201 Created)
{
  "status": "success",
  "client_id": 19,
  "employee": {
    "id": 14,
    "extension": "102",
    "display_name": "سارة الخالد",
    "department": "خدمة العملاء والدعم الفني",
    "status": "ready"
  }
}
GET POST/PUT DELETE /api/partner/v1/clients/{client_id}/employees/{employee_id}/
إدارة موظف محدد

تعديل بيانات الموظف (الاسم، القسم، التحويلة، كلمة المرور)، أو حذفه نهائياً وحذف حسابه.

👥طوابير الانتظار وتوزيع المكالمات (Call Queues & Memberships)

GET POST /api/partner/v1/clients/{client_id}/queues/
طوابير المكالمات

إنشاء طابور رنين للموظفين البشريين (بالتناوب Round-Robin أو رنين جماعي Ring-All) وتعيين موظفي الطابور مباشرة.

POST Body (إنشاء طابور مع الأعضاء)
{
  "name": "طابور الدعم الفني VIP",
  "code": "301",
  "strategy": "round_robin",
  "ring_timeout_seconds": 20,
  "total_timeout_seconds": 60,
  "fallback_action": "ai_assistant",
  "members": [14]
}
Response (201 Created)
{
  "status": "success",
  "queue": {
    "id": 8,
    "name": "طابور الدعم الفني VIP",
    "code": "301",
    "strategy": "round_robin",
    "members": [{ "id": 14, "display_name": "سارة الخالد", "extension": "102" }]
  }
}
POST /api/partner/v1/clients/{client_id}/queues/{queue_id}/members/
إدارة أعضاء الطابور

إضافة موظف لطابور معين، حذفه، أو مزامنة كافة الأعضاء بدفعة واحدة عبر تمرير action: "add" | "remove" | "set".

📚قواعد المعرفة والاستعلام الدلالي (RAG & Semantic Search)

POST /api/partner/v1/clients/{client_id}/documents/
رفع وفهرسة مستند

رفع ملفات PDF / Word أو نصوص خام ليتم تقطيعها وتوليد التضمينات الدلالية عبر Gemini وحفظها في قاعدة المتجهات pgvector.

POST /api/partner/v1/clients/{client_id}/rag/query/
استعلام دلالي ذكي
Request (JSON)
{
  "query": "ما هي شروط وسياسة التوصيل المجاني لديكم؟",
  "top_k": 2
}
Response
{
  "status": "success",
  "client_id": 19,
  "total_matches": 1,
  "results": [
    {
      "content": "التوصيل مجاني لكافة مدن المملكة للطلبات فوق 200 ريال...",
      "similarity": 0.7949
    }
  ]
}

📞السنترالات والخطوط الصادرة وربط الأرقام (Telephony & DIDs)

GET POST /api/partner/v1/clients/{client_id}/telephony/numbers/
ربط الأرقام و DIDs

ربط أرقام الاستقبال المباشرة (DIDs) بسنترال العميل وتحديد توجيه المكالمات وتوليد إعدادات Issabel PBX فورياً.

⚡بدء مكالمة صوتية مباشرة (LiveKit WebRTC Token)

POST /api/partner/v1/clients/{client_id}/token/
إصدار توكن الغرفة

يتحقق تلقائياً من رصيد الشريك وسقف استهلاك العميل، ويصدر توكن اتصال صوتي مشفر لمحادثة الذكاء الاصطناعي في متصفح أو تطبيق العميل.

🪝الويبهوك والتوقيع الرقمي (Webhooks & HMAC-SHA256)

عند انتهاء كل مكالمة أو تسجيل عميل جديد، ترسل منصتنا إشعاراً فورياً إلى رابط الـ Webhook المحدد في إعدادات الشريك. يتم توقيع كل طلب برمجياً عبر تشفير HMAC-SHA256 في هيدر X-Partner-Signature.
